# Changelog

## 1.0.2

- Kept supported vanilla menus visible when other mods add extra controls. Added controls are excluded from shared panels.
- Fixed chat panels drifting when the observer moves or turns the camera.
- Improved cursor alignment with vanilla inventory and chest slots when an addon changes the layout.
- Added separate chat and command sharing controls in My menus. Ordinary chat text is shared by default; commands and unsupported-menu placeholders are hidden by default. Existing saved choices are kept.

## 1.0.1

- Added a live preview beside WIGO settings, showing your skin and panel appearance. Drag to rotate and scroll to zoom.
- Fixed shared Esc menus shifting when other mods add extra buttons.
- Added support for Esc menus modified by Essential.
- Fixed curved WIGO settings panels shifting when viewed from the opposite side.
- Improved text contrast in shared WIGO settings for better readability.
